🛠️ Especificaciones Técnicas del ADN Congoleño (Brazzaville)
Este contrato documenta el sellado de fluidos y la rotura de fibras vegetales:

Hermeticidad Liboké (uint256): Cuantifica la eficiencia del sellado geométrico de las hojas de plátano. Un nivel 10 representa un cierre hidrostático perfecto donde el alimento se cocina en su propia humedad residual sin pérdida de vapor.

Grado de Trituración (uint256): Mide la intensidad de la molienda manual del Saka-Saka (hojas de mandioca). Este proceso es vital para romper las paredes celulares de la hoja y permitir una emulsión homogénea con los lípidos del aceite de palma.

Usa Aceite de Palma (bool): Validador del uso de esta base lipídica, esencial para la absorción de vitaminas liposolubles presentes en las hojas verdes.

Sistema de Feedback: Funciones de darLike y darDislike integradas para la interacción comunitaria.
